# Moodle EPUB Reader Activity (`mod_readepub`)

This Moodle activity module allows teachers to upload and display `.epub` files securely using the [Bibi EPUB Reader](https://github.com/satorumurmur/bibi).

The key thing is that the epubs must be unzipped and in bibi-bookshelf which means updating this plugin updates the epubs.
